# P3 Fig. 19 기반 Bang-Bang CDR 및 DB HiTek MOS 수신 검증

**검증일:** 2026-11-12

**원 논문:** K.-L. J. Wong *et al.*, "A 27-mW 3.6-Gb/s I/O Transceiver," *IEEE J. Solid-State Circuits*, vol. 39, no. 4, pp. 602–612, Apr. 2004, 특히 Fig. 18–21.

**실행 기록:** [GitHub Actions 43159596701, PASS](https://github.com/khi103/EEE6682-Presentation/actions/runs/43159596701).

## 1. 실제 검증한 대상

논문 Fig. 19의 E0, D0, E1, D1 Edge/Data Sample 및 4-XOR 기반 Early/Late Up/Down 구조를 바탕으로, 입력 비트 정답을 모르는 상태에서 위상 제어 코드를 갱신했다.

- 3.6-Gb/s MOS TX: DB HiTek 180 nm SVT NMOS 8:4:2:1 분할 출력단, 2-Tap FFE (α=0.30).
- Channel: 실제 RG58/FR4 측정 모델이 아닌 두 개의 RC Pole (약 −12 dB @1.8 GHz).
- Fig. 19 계열 CDR: Data/Edge Sample, XOR Up/Down 판정, Collision Suppression, 4-UI 또는 16-UI 단위 Counter Update, 7-bit Saturating Counter. **Controller는 Python으로 실행**된다.
- Fig. 20 계열 7-bit MOS Charge Pump: 별도 ngspice DC 156회에서 얻은 **실제 NMOS/PMOS 전류 코드 LUT**를 사용한다.
- Current-to-Clock Phase: 논문 Fig. 21의 최대 약 350-ps 위상 범위를 정규화해 전류 코드 LUT에 연결한 **가정한 전달함수**. 실제 MOS Charge Pump→PLL→Clock Delay Transfer Function을 얻은 것이 아니다.
- RX: 두 개의 물리 PMOS 입력 재생 Latch를 실제 ngspice에서 구동하고, `|Q−QB| ≥ 150 mV`인 샘플만 판정 성공에 포함한다.

**시뮬레이션 형식:** 2-Pass Co-simulation. 먼저 MOS TX/RC와 Charge Pump MOS 전류를 추출하고, 입력 데이터 정답을 사용하지 않는 Controller가 위상/코드를 시간 순서대로 갱신한다. 이후 복구된 클록을 **이상적인 PWL Source**로 표현해 물리 MOS RX Latch를 다시 ngspice에서 구동한다. 따라서 **전 회로가 한 SPICE 회로 내부에서 실시간 동작하는 물리적 CDR는 아직 아니다.**

## 2. 엄격한 재현 결과

PRBS7 512비트 중 초기 수렴 및 끝단을 제외한 378비트를 비교했고, 수신 Latch의 차동 재생 전압 기준 150 mV를 만족해야 유효한 데이터로 인정했다. 시뮬레이션 수행 후 정수 UI Framing Offset만 맞추며, 이 정보는 CDR 제어기에 입력하지 않는다.

| 제어 | 초기 7-bit Counter | Receiver Clock Error | Update Interval | 최종 Counter | 실제 MOS RX 오류/378 |
|---|---:|---:|---:|---:|---:|
| CDR ON | 15 | 0 ppm | 4 UI | 8 | **0** |
| CDR ON | 100 | 0 ppm | 4 UI | 102 | **0** |
| CDR ON | 15 | 0 ppm | 16 UI | 8 | **0** |
| CDR ON | 100 | 0 ppm | 16 UI | 102 | **0** |
| CDR ON | 15 | +1000 ppm | 4 UI | 1 | **0** |
| **CDR OFF** | 15 | +1000 ppm | 없음 | 15 | **5**, 미재생 5 |
| CDR ON | 30 | 0 ppm | 16 UI | 8 | **0** |
| CDR ON | 127 | +1000 ppm | 4 UI | 58 | **0** |
| **CDR OFF** | 127 | +1000 ppm | 없음 | 127 | **30**, 미재생 30 |

가장 강한 비교군에서 초기 Counter 127, +1000 ppm 오차를 적용하자, **CDR 비활성화 30/378 오류 → CDR 활성화 0/378 오류**로 개선되었다. 이 결과는 Fig. 19 유사 알고리즘이 입력 데이터의 Edge를 감지해 실제 MOS Latch의 판정 위상을 조정할 수 있다는 정량적 근거다.

수신이 378비트에서 무오류였더라도 이는 실제 실리콘 BER 10⁻¹² 또는 논문의 전체 PLL/CDR 지터 성능 증명이 아니다.

## 3. 아직 재현하지 못한 것

1. 논문 Fig. 18–20의 실제 450-MHz PFD, Divider, Switched-Capacitor Filter, 7-bit MOS Charge Pump의 스위칭을 포함한 **동일 넷리스트 폐루프**.
2. 원문 Fig. 14의 M1–M19 Comparator와 Digitally Calibrated Offset DAC 및 실제 Clocked Latch의 원래 연결.
3. Charge Pump의 DC Current vs Code가 Clock Phase Shift로 변환되는 **물리 MOS VCO/PLL 전달함수**. 현 테스트의 350 ps Phase Range는 논문 실측 범위를 반영한 가정이다.
4. 송신 Pre-driver의 소자 및 Slew Control, 실제 8-cm FR4 + 6.5-m RG58의 복소 S-parameter, 실제 0.18-µm 원저자 PDK와 Post-layout Parasitic.
5. 27.12-mW Total Link Power, 실측 37 mV × 189 ps Eye와 BER.

**동일 넷리스트 in-SPICE 데이터 위상 피드백도 별도 시도했다.** 실제 MOS TX, RX, VCO, FLL Bias Loop에 B-source Data Edge Detector를 연결했지만 검증한 Gain/Reference 조건에서는 주파수 수렴과 수신 데이터 판정이 **동시에 기준을 만족하지 못했다**. 따라서 해당 회로는 **LOCK 실패**이며, [코드](../simulation/p3_in_spice_data_transition_cdr.py)와 [실행 기록](https://github.com/khi103/EEE6682-Presentation/actions/runs/43158168032)을 통해 수치로 확인할 수 있다.

## 5. 논문 발표 시 사용할 수 있는 결론

**한국어:** 0.18-µm MOSFET 회로에서 생성된 실제 TX 및 RX 파형을 바탕으로, Fig. 19의 4-XOR Bang-bang CDR 구조를 적용한 결과 ±초기 위상과 +1000-ppm 클록 오차 조건에서 수신 Latch의 오류가 줄어드는 것을 확인했다. 다만 MOS Charge Pump의 코드별 전류로부터 위상 이동을 추정하는 전달함수는 이상화하였으며, 원 논문 ASIC의 실제 듀얼 루프 PLL을 복원한 것은 아니다.

**IEEE-style academic English:** "A Fig. 19-inspired bang-bang timing-recovery algorithm was evaluated using transistor-level transmitter and receiver waveforms obtained from a 0.18-µm CMOS process model. With a 1000-ppm receiver clock-frequency offset and an unfavorable initial phase code, the number of unresolved or incorrect receiver decisions decreased from 30 to 0 over 378 evaluated bits. The phase actuation was modeled using a normalized, transistor-characterized charge-pump current lookup table; therefore, the result does not establish transistor-level closed-loop PLL equivalence to the reported silicon."

**영어 표현의 뉘앙스:** *transistor-characterized*는 실제 MOS 모델로 전류를 산출했다는 뜻이고, *phase actuation was modeled*는 전류를 실제 PLL에서 위상으로 변환한 것이 아니라 가정한 수식으로 모델링했다는 뜻이다. 마지막 문장은 원 저자 실리콘 전체의 재현과 분리한다.
