# EEE6682 P3: Full-Link Integrated MOS Reconstruction Status (2026-11-12)

**Scope:** Independent 0.18-µm DB HiTek SVT circuit-level reconstruction, **not** an exact implementation of the 2004 silicon of K.-L. J. Wong *et al.*, "A 27-mW 3.6-Gb/s I/O Transceiver," *IEEE Journal of Solid-State Circuits*, vol. 39, no. 4, pp. 602–612, Apr. 2004.

**검증 원칙:** "실제 PDK MOSFET이 ngspice에서 동작했다"와 "원 논문 전체 칩을 그대로 재현했다"를 엄격히 구분한다. 실리콘 동등성, 제조공정 특성 정확도, BER 10⁻¹² 및 실제 27.12-mW 전력은 이번 실행으로 입증되지 않는다.

| 단계 | 실제 물리 회로 | 아직 이상화된 블록 | 결과/근거 |
| --- | --- | --- | --- |
| 1.8 GHz 동적 재생 Comparator | DB HiTek PMOS 입력 차동쌍 + NMOS Regeneration + Reset | 입력 패턴과 클록 PULSE | [TT/FF/SS, ±40/80 mV 각 15/15 판정 성공](https://github.com/khi103/EEE6682-Presentation/actions/runs/43151118049) |
| MOS TX → RC 채널 → 2-Lane MOS RX | 8:4:2:1 NMOS 분할 드라이버 + 2 MOS 재생 Latch | FFE 디지털 게이트 제어와 1.8-GHz 클록 PULSE, RC 채널 | [TT/FF/SS에서 FFE on/off 각 104/104 판정 성공](https://github.com/khi103/EEE6682-Presentation/actions/runs/43151739466) |

**중요:** Phase-Sampling Offset의 오프라인 탐색은 실제 CDR 잠금 기능이 아니다. 실제 VCO가 발진하더라도 원 논문 Dual-Loop PLL이 닫혀 있다는 뜻도 아니다. 특히 재구성 단위 MOS의 치수, 레이아웃, Comparator 및 Ring Oscillator는 저자의 원래 치수가 아니다.

## 2. 실제 3.6 Gb/s MOS TX, RX 및 MOS VCO 단일 넷리스트 결과

- **Data Rate:** 3.6 Gb/s NRZ, PRBS7 128비트.
- **TX:** DB HiTek 1.8-V SVT NMOS 8:4:2:1 분할 출력단, 0.5-V 신호 전원, 50-Ω Receiver Termination, 2-Tap FFE α=0.30.
- **Channel:** 두 개의 이상적 버퍼로 분리된 50-Ω/3.053-pF RC Pole (약 −12 dB @ 1.8 GHz). 실제 FR4/RG58 측정 채널은 아님.
- **RX:** 2-Lane 하프레이트 PMOS 입력 동적 재생 MOS Latch (1.8 GHz 클록).
- **Clock:** DB HiTek PMOS/NMOS 3단 MOS Ring VCO, CMOS Inverter Buffer로 두 상반 클록 생성. Python 외부 주파수 검색으로 VCO Bias 조절, 수신 샘플 위상/Parity를 PRBS 학습으로 선택.
- **NGSPICE:** 각 비교조건을 동일 PDK MOS로 한 회로도에서 12번의 실제 ngspice 실행으로 재현.

| 측정 | No FFE | 2-Tap FFE α=0.30 |
| --- | ---: | ---: |
| 최종 MOS VCO 발진 주파수 | 1.799238 GHz | 1.799234 GHz |
| 물리 MOS Latch 판정 오류 수 | 0/104 | 0/104 |
| 1.8-V VDD 전원에서 VCO/수신 MOS 및 클록 버퍼 전력 | 2.4414 mW | 2.4513 mW |
| 0.5-V 신호 공급 MOS TX 소비 | 0.6843 mW | 0.9225 mW |
| 위 두 전원에서만 합산한 부분 전력 | 3.1257 mW | 3.3738 mW |

**이 전력은 원 저자의 전체 27.12-mW Active Link Power와 비교할 수 없다.** TX의 이상적 PWL 게이트 신호 발생, 수신 종단 VREF, 물리적 PFD/Charge Pump/PLL Loop, 실제 Comparator Offset Calibration 및 2:16 Demultiplexer와 Channel 종단 보조 전원 소비가 포함되지 않는다. MOS Clock Domain과 Latch는 하나의 1.8-V VDD 소스에 묶여 있으므로 **그 전력을 독립적으로 분리해서 측정한 값도 아니다**.

BER 0이라는 결과는 104개 패턴 샘플에 대한 관측 오류가 없다는 뜻이지, BER 성능이나 실제 Robustness 보증을 의미하지 않는다. 입력 패턴과 수신 샘플 최적화에 동일한 PRBS를 사용했으므로 **CDR의 독립 검증도 아니다**.

## 3. 이전까지 수행한 블록별 보정

- **Fig. 8 Replica:** DB HiTek NMOS와 ngspice 아날로그 B-source Integrator가 TT/FF/SS/FS/SF에서 약 50 Ω 기준점으로 수렴. 그러나 전체 16-Code 드라이버 PAD에서 코드별 실제 출력 저항이 보장되는 것은 아님.
- **Fig. 14 Comparator:** 정확한 원문 M1–M19 회로는 미완료. 기존 PMOS Preamp만의 1.8-GHz 동작 실패를 보완하려고 독립적인 PMOS 입력 동적 MOS Latch를 추가했고, Standalone 1.8-GHz 입력에서 판정 성공.
- **Fig. 20 Charge Pump:** 물리적 7-bit NMOS Weighted Current DAC의 DC 선형 특성은 검증했으나 실제 Switched Pump, PLL Loop에는 연결하지 않았다.
- **PLL/CDR:** 별도 Python 행동 모델 및 MOS Charge Pump LUT 기반 이상화된 PLL 응답은 확인. 실제 PFD/CP/Loop Filter/VCO/Clock Recovery를 통째로 물리 MOS의 닫힌 루프로 재현하지 못했다.

## 4. 다음에 반드시 필요한 검증

1. **실제 PLL/CDR 폐루프:** VCO가 외부 바이어스 보정과 PRBS 위상 탐색 없이 기준 클록 및 입력 데이터 위상에 스스로 수렴하는지. 클록 출력과 Serial RX가 같은 회로에서 살아 있어야 한다.
2. **실제 저자 Fig. 14 CMOS Comparator:** 1.8 GHz의 최소 Differential Input Swing, 재생 시간과 Random Offset Distribution을 검증. 현재 Standalone MOS Latch는 별도 설계다.
3. **원 논문 채널:** 교수 제공 차동 FR4-like .s2p/.s4p를 50-Ω Single-Ended 환경에 맞게 변환하고, 별도로 실제 8 cm FR4 + 6.5 m RG58 S-parameters를 확보하거나 물리적 근사값을 명확히 구별해야 한다.
4. **전체 공정 모델 정확성:** ngspice가 일부 HSPICE-only BSIM Model Parameter를 무시하므로 HSPICE/Spectre 기준 I–V/C–V 및 Transient Correlation이 필요하다.
5. **Full-Link Power:** 실제 PFD/CP/VCO, Driver Gate Buffer, Comparator, Demultiplexer 및 Clock Buffer를 모두 공급 전류에 포함해야 한다.

## 6. 추가 성공: 하나의 ngspice 회로 안에서 클록 주파수 피드백도 연결

이전 단순 VCO 연결은 주파수를 **SPICE 외부 Python에서 먼저 찾은 다음** 고정 바이어스로 재현했지만, 후속 실험에서는 실제 MOS VCO의 출력을 기준 1.8 GHz 클록과 비교하는 Behavioral Frequency Detector, 제어 전류원 및 20-pF Loop Capacitor를 **동일한 ngspice Netlist 안에 배치**했다.

- 구동 블록: 실제 DB HiTek MOS TX / PMOS-input 재생 RX Latch / 3단 MOS Ring VCO / MOS Clock Buffer
- 피드백 블록: 비교기 및 Edge-Rate Detector는 ngspice Ideal B-source로 구성, 실제 제어 Loop Capacitor 존재
- 외부 기준: 이상적인 1.8 GHz Reference Clock Source
- 초기 조건: VCO Gate Bias 1.0 V, 초기 FLL 수렴 시간을 먼저 둔 뒤 TX PRBS 전송 시작
- 시험 데이터: 3.6 Gb/s NRZ, 2-Tap TX FFE α=0.30, PRBS7 128 bit 중 104 bit 비교
- **후속 성공 실행:** [GitHub Actions 43154346365](https://github.com/khi103/EEE6682-Presentation/actions/runs/43154346365)
- **측정 결과:** MOS VCO 최종 주파수 **1.818748 GHz**, 목표 1.8 GHz 대비 약 **+1.04%**. MOS RX의 오프라인 패턴 기준 최적 위상/Parity에서 **0/104 판정 오류**.

성공 전, 실제 회로에서 Reference-Edge Detector의 Gain이 MOS Buffer Loading에 충분히 맞지 않아 1.615 GHz(6/104 Error) 또는 1.987 GHz(3/104 Error)로 벗어나는 실패 사례도 기록되었다. 따라서 지금의 제어 파라미터는 **TT 조건에서 반복 조정한 실험값**이며 PVT·Loop Stability·Lock Range가 보증된 회로값이 아니다.

**여전히 중요한 미구현 사항:** 실제 P3 Fig. 18–20의 PFD, Binary-Weighted Switched Charge Pump, Dual-Loop Architecture, Digital Phase-Shifter, Actual Jitter Transfer Function 및 Real-Time CDR이 아니다. 특히 수신 측이 알려진 PRBS 전체 패턴을 사용해 오프라인으로 최적 위상·Parity를 선택하므로 **Data Phase Recovery의 In-Circuit Feedback은 아직 구현되지 않았다**. 주파수 근접 및 104 샘플 무오류로 원 논문의 PLL/CDR 및 BER 성능을 검증했다고 주장할 수 없다.
