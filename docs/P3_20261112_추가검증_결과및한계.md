# P3 논문 재현 및 잔여 검증 종합 결과 (2026-11-12)

## 0. 분석 대상과 검증 원칙

- 논문: K.-L. J. Wong, H. Hatamkhani, M. Mansuri, and C.-K. K. Yang, "A 27-mW 3.6-Gb/s I/O Transceiver," *IEEE J. Solid-State Circuits*, vol. 39, no. 4, pp. 602-612, Apr. 2004, doi: [10.1109/JSSC.2004.825259](https://doi.org/10.1109/JSSC.2004.825259).
- 대상 기술: 저전력 3.6 Gb/s 링크, 2-Tap Voltage-Mode Pre-emphasis, 약 50 Ω 송신 소스 종단, 고속 수신 비교기, 450 MHz 기준 PLL과 디지털 위상 복구.
- 현재 환경: 강의 Verilator 기반 링크, 독립 Python 채널 대체 모델, DB HiTek 180 nm SVT 트랜지스터 모델을 사용한 ngspice 42 및 XSPICE 혼합신호 회로. **DB HiTek 공정은 원 논문의 2004년 실리콘 PDK와 같다고 증명되지 않았다.**
- 판정 기준: 실제 MOS SPICE 시뮬레이션, XSPICE 혼합신호 모델, 행동 모델, 원 논문 실측치를 반드시 구분한다. 오류 없는 수십 또는 수백 비트 판정은 통계적인 BER 증명이 아니다. 모델 또는 스크립트 실행 성공 자체가 원 논문의 재현 성공이라는 뜻은 아니다.
- PDK 라이선스: 원본 파운드리 모델의 제3자 호스팅 및 배포 권한을 별도로 확인해야 한다. 이 문서에는 모델 계수를 복제하지 않는다.

## 2. FFE ON/OFF 검증의 샘플 중복 문제와 교정

초기 TX FFE 계수 비교는 물리 MOS Latch 출력 시각을 송신 비트 인덱스에 `round()`로 대응시켰다. 실제 전기적 클록 지터와 특정 패킷 위상에서 이 방식은 서로 다른 물리 샘플을 같은 비트에 연결할 수 있었다. 따라서 기존의 18/226, 9/226, 2/226, 10/226 수치를 독립된 비트의 오류율처럼 사용해서는 안 된다.

이를 수정하기 위해 다음을 적용했다.

1. 실제 물리 클록의 샘플 시간을 송신 UI 구간에 `floor()`로 대응시키고, 누락된 비트는 오류에 포함했다.
2. 중복된 UI 샘플은 별도 개수로 기록하며, 비트 정답과 무관한 일관된 규칙으로 대표 시각을 고른다.
3. FFE 네 조건에 동일한 정수 UI Lag를 사용한다. 이 Lag는 앞부분 Training Data로만 설정한다.
4. 이후 구간에 대해서만 평가한다. PRBS31에서 학습 구간은 인덱스 [18, 144), 검증 구간은 [144, 502)이다.
5. 이 정수 Lag 보정은 오직 실험 결과 채점용이며, 실제 수신기의 CDR 또는 Framing Circuit을 구현한 것은 아니다.

**따라서:** FFE가 없는 경우보다 FFE 적용 시 판정이 개선된 것은 독립 패턴에서 반복 확인되었다. 그러나 현재 패턴과 평가 기준으로는 0.15, 0.30, 0.45 사이의 오류 수 차이를 구별할 수 없다. 논문에서 사용한 α=0.30을 우리 회로의 전역 최적 계수로 주장할 근거는 없다. 2건의 공통 누락은 전체적으로 검증 완료된 358개의 유효 데이터 판정이라는 의미가 아님을 보여준다.

## 4. 발표에서 방어 가능한 핵심 결론

- 원 논문의 전압형 2-Tap FFE 개념은 서로 다른 SystemVerilog/Verilator, Python, MOS SPICE 모델에서 수신 Eye 또는 판정 마진이 좋아지는 방향으로 확인되었다.
- MOS 소스 출력의 약 50 Ω 정합은 한 동작점의 저항만 측정해서 보장할 수 없다. 실제 PAD 전압별 임피던스 변화와 FF/FS/SF 루프 불안정성은 피드백과 PVT 보정의 중요성을 보여준다.
- 별도로 설계한 실제 DB HiTek 180 nm MOS Charge Pump와 VCO를 사용하는 450 MHz 기준 PLL이 명시된 TT 조건에서 동작했다. 그러나 전체 PVT와 데이터 CDR는 아직 검증하지 못했다.
- 수신 데이터 제어를 물리 MOS PLL의 루프 노드에 직접 넣었을 때 조건부 오류 감소는 관측됐지만, 실제 Fig. 19 물리 CDR 완성 및 Lock은 아니다.
- PRBS31에서 검증 데이터로 평가한 FFE 계수 0.15/0.30/0.45 사이의 오류 차이는 관측되지 않았다. 계산 방식과 데이터 커버리지까지 독립 검토해야 정직한 재현 비교가 된다.

**IEEE-style academic English for presentation:**

> A 3.6-Gb/s link incorporating a transistor-level CMOS transmitter, regenerative receiver latches, and a reference-locked mixed-signal PLL was evaluated using a 0.18-μm process model. Under a common integer-alignment procedure, the number of unresolved or incorrect decisions decreased from 27 to 2 over 358 held-out PRBS31 symbols when two-tap pre-emphasis was enabled. The remaining two events corresponded to missing samples, whereas no incorrect regenerated decisions were observed for the evaluated pre-emphasis settings. A separate behavioral data-phase detector coupled to the physical PLL reduced receiver errors from 40 to 6 over 227 decisions in one phase-offset scenario. These results support the feasibility of the reconstructed signal-chain concepts but do not establish circuit-level equivalence to the published transceiver, full PVT robustness, or a validated data-recovery lock range.

**한국어 번역 및 표현의 뉘앙스:**

> 0.18 μm 공정 모델을 사용하여 트랜지스터 수준 CMOS 송신기, 재생형 수신 Latch 및 기준 클록에 동기화된 혼합신호 PLL을 포함하는 3.6 Gb/s 링크를 평가했다. 공통 정수 비트 정렬 절차를 적용한 PRBS31 검증 구간 358비트에서 2-Tap Pre-emphasis 활성화 시 미재생 또는 오판정 수가 27개에서 2개로 감소했다. 남은 두 건은 샘플 누락이었으며, 평가한 FFE 설정에서는 유효하게 재생된 데이터의 잘못된 판정은 관측되지 않았다. 별도의 행동 모델 기반 데이터 위상 검출기를 물리 PLL에 연결한 실험에서도 특정 초기 위상 오차 조건에서 227개 판정 중 오류가 40개에서 6개로 감소했다. 이 결과는 독립적으로 재구성한 링크 개념의 구현 가능성을 뒷받침하지만, 원 논문과의 완전한 회로 일치, 전체 PVT 견고성 또는 데이터 복구 Lock Range를 증명하지는 않는다.

"transistor-level"은 송신기, 수신 Latch, 전하 펌프 및 VCO의 실제 MOS 소자 모델을 사용했다는 뜻이다. "reference-locked mixed-signal PLL"은 XSPICE 디지털 PFD와 MOS 물리 회로가 결합된 기준 클록 PLL이며, 데이터 기반 원문 CDR를 재현했다는 의미가 아니다. "held-out"은 정수 패킷 정렬을 결정하는 데 사용하지 않은 평가 데이터라는 뜻이다. "support the feasibility"는 원리상의 가능성을 뒷받침한다는 제한적 진술이며, 원저자의 실리콘 성능을 입증했다는 뜻이 아니다.
