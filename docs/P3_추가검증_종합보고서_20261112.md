# EEE6682 P3 추가 검증 보고서 (2026-11-12)

## 목적과 범위

이 문서는 추가 검증 작업만 다룬다. **PPT는 수정하지 않았다.**

K.-L. J. Wong *et al.*, "A 27-mW 3.6-Gb/s I/O Transceiver," *IEEE J. Solid-State Circuits*, vol. 39, no. 4, pp. 602–612, Apr. 2004의 전압 모드 TX FFE, 소스 종단, 저전력 신호 전송을 여러 시뮬레이션 수준에서 검증한다.

**중요:** 서로 다른 시뮬레이션 결과의 Eye 수치가 다르다고 해서 원 논문이 틀렸거나 회로 재현에 성공했다는 의미는 아니다. 채널, 신호 기준, 소자, 수신기와 출력 스윙 조건이 서로 다르다.

## 2. 강의 원본과 수정 Verilator 재현의 정량 비교

교수님 원본 코드는 56 Gb/s, 3/5/9-Tap FFE에 Zero-Forcing과 `Σ|c_i|=1`을 적용한다. 이를 임시 복사한 실제 SystemVerilog 링크에서 3.6 Gb/s NRZ, 0.25 Vpp, 2-Tap `α=0.30`으로 변경하고, 1.8 GHz의 12 dB 손실을 갖는 인공 RC2 채널을 생성했다. **원본 코드 파일은 그대로 보존했으며, 수정 사항은 별도 스크립트로 추적된다.**

| 경우 | 수신 Eye Height | Eye Width |
| --- | ---: | ---: |
| 원본 56 Gb/s, 강의 채널, FFE 없음 | -130.22 mV (닫힘) | 0 ps |
| 원본 56 Gb/s, 강의 채널, 3-Tap ZF | 70.58 mV | 11.72 ps |
| 원본 56 Gb/s, 강의 채널, 5-Tap ZF | 72.89 mV | 12.83 ps |
| 원본 56 Gb/s, 강의 채널, 9-Tap ZF | 74.84 mV | 12.83 ps |
| 수정 3.6 Gb/s, RC2, FFE 없음 | 35.17 mV | 156.26 ps |
| 수정 3.6 Gb/s, RC2, 2-Tap FFE | **67.63 mV** | **243.07 ps** |
| 수정 3.6 Gb/s, RC2, 3-Tap ZF | 55.62 mV | 190.98 ps |
| 수정 3.6 Gb/s, RC2, 5-Tap ZF | 58.76 mV | 199.66 ps |
| 논문 Fig. 25 실제 실측, 2-Tap | **37 mV** | **189 ps** |

56 Gb/s 원본과 3.6 Gb/s 수정본은 채널과 스윙 조건이 다르므로 같은 비교군이 아니다. 논문 실측 결과와 Verilator 값도 절대 수치가 일치하지 않는다.

실행 증거: [Verilator 원본과 수정 코드](https://github.com/khi103/serdes-lecture-site/blob/main/linksim_H-L/p3_verilator_reproduce.py), [실제 실행](https://github.com/khi103/serdes-lecture-site/actions/runs/43139646362).

## 3. 채널이 다른데 Nyquist 손실만 같으면?

1.8 GHz에서 손실을 동일하게 12 dB로 설정한 세 채널을 실제 Verilator에서 재시험했다.

| 합성 채널 | FFE 없음 | 2-Tap FFE |
| --- | ---: | ---: |
| 1-Pole RC | 6.17 mV | 65.72 mV |
| 2-Pole RC | 35.17 mV | 67.62 mV |
| 3-Pole RC | 46.01 mV | 66.67 mV |

**결론:** Nyquist 한 지점의 손실이 같아도 Eye 결과는 크게 달라진다. 반면 시험한 세 합성 채널에서 FFE 개선 방향은 공통으로 확인됐다. 실제 RG58/FR4 채널의 수치 재현은 미완료다.

## 4. MOS 드라이버 회로와 PVT 결과

독립적으로 만든 NMOS-only 8:4:2:1 드라이버를 50 Ω 수신 종단에 연결하고, MOSFET의 실제 전류와 전압을 ngspice에서 계산했다.

- TT, 27°C에서 **0.25 V 고정 기준점**의 증분 출력 저항: **49.20–50.72 Ω** (16 코드)
- 각 코드의 **실제 DC 출력 전압**에서 저항: **35.92–50.35 Ω** (같은 16 코드)
- 출력 스윙 **285.99 mVpp**로 논문의 목표 250 mVpp와 다름
- 같은 샘플 위상에서 2-Tap FFE 수신 Eye Height **50.96→90.01 mV**
- 0.5 V 신호 공급 평균 전력의 종전 샘플 평균 **0.780→1.014 mW**, 프리드라이버/1.8 V 게이트 회로/수신기 전력 제외
- 공정 FF/SS에서 고정된 크기의 출력 저항이 크게 달라져 보정의 필요성을 보여줌

회로 구조와 수치: [실행 코드](../simulation/p3_transistor_driver.py), [전체 검증 결과](p3_driver_spice_results_2026-11-11.md).

## 5. 이상적 보정과 Slew 한계

각 Corner에서 **NMOS 단위 폭**을 수치적으로 재조정하면 50 Ω 기준점에서 TT/FF/SS/FS/SF 모두 49.99–50.01 Ω 근처로 맞출 수 있었다. FF에서 배율은 약 0.856, SS에서는 약 1.171이다. 하지만 각 코드의 실제 PAD 동작 전압에서 오차가 남는다. 이 결과는 원 논문 Fig. 8의 물리적 피드백 제어 회로 구현과 동등하지 않다.

게이트 전환을 2 ps에서 180 ps로 느리게 해도 동일한 위상에서 FFE Eye 개선이 유지됐다. 노이즈·지터·Offset·CDR 민감도도 별도 검증했지만 원 논문의 물리적 Pre-driver, Comparator, PLL이 아니다.

## 6. 원 논문의 실제 성능을 여전히 확정하지 못하는 이유

1. **다른 PDK:** DB HiTek 0.18 µm는 논문에 사용된 정확한 2004년 칩 PDK와 같다고 보장되지 않는다.
2. **ngspice 모델 호환:** HSPICE 전용 파라미터 일부가 무시된다. HSPICE 참조 I–V/C–V 비교 없이 모델 정밀도를 보장할 수 없다. [상관관계 비교 절차](hspice_ngspice_correlation_pending.md).
3. **재구성 회로:** 8:4:2:1 구조와 MOS 전압모드 전환 원리는 구현했지만 원문 제어 회로 및 레이아웃, 정밀 바이어스와 출력단 설계가 없다.
4. **채널:** 8 cm FR4 + 6.5 m RG58의 전체 복소 S-parameter와 패키지가 없다. 12 dB 손실 한 점만으로 동일 Eye를 만들 수 없다.
5. **수신기/클록:** Ideal/Synthetic 모델을 시험했지만 실제 Comparator, Offset Cancellation, PLL/CDR의 전체 전류 및 지터 성능이 아니다.
6. **실리콘 데이터:** 실제 칩의 27.12 mW, 37 mV×189 ps 및 수신 BER 성능을 우리 환경에서 실측한 자료가 없다.

**현재 과제의 추가 검증 성공 범위**는 실제 Verilator 시스템 모델, 독립 MOS 출력 드라이버 ngspice 모델, 그리고 저전력 링크의 주요 Trade-off에 대한 정량적 비교다. 원 논문의 실리콘을 동일하게 복제했다고 주장하지 않는다.
