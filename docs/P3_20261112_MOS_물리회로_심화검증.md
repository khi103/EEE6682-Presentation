# P3: 180 nm MOS 물리 회로 심화 검증 및 재현 범위 평가

**실험일:** 2026년 11월 12일  
**대상 논문:** K.-L. J. Wong, H. Hatamkhani, M. Mansuri, and C.-K. K. Yang, "A 27-mW 3.6-Gb/s I/O Transceiver," *IEEE J. Solid-State Circuits*, vol. 39, no. 4, pp. 602–612, Apr. 2004, doi: 10.1109/JSSC.2004.825259.  
**관련 이전 종합 보고서:** [P3 이전 검증과 한계](P3_20261112_추가검증_결과및한계.md).

## 1. 검증 대상, 모델 및 성공 판정 기준

- 트랜지스터는 DB HiTek 180 nm, 1.8 V SVT MOS 모델을 ngspice 42에서 실행했다. 이 모델은 원 논문 실리콘과 같은 PDK라고 보장되지 않는다. HSPICE 전용 BSIM 파라미터가 일부 무시되어, 원본 HSPICE/Spectre와의 수치 상관은 미완료다.
- 독립 TX: 8:4:2:1 NMOS segmented voltage-mode driver. 독립 RX: 두 개의 half-rate PMOS-input regenerative MOS latch, \(|Q-QB|\geq 150\;\mathrm{mV}\) 기준.
- 독립 PLL: XSPICE 디지털 450 MHz PFD / 4분주기, 물리 NMOS/PMOS 7-bit switched charge pump, RC loop filter 및 DB HiTek MOS 3단 ring VCO. reference PLL이며 serial-data CDR의 모든 기능과 동일하지 않다.
- 채널: 1.8 GHz에서 약 12 dB 손실인 두 개의 buffered RC Pole. 실제 8 cm FR4 + 6.5 m RG58의 측정 복소 Touchstone이 아니다.
- 이상적 요소: 기준 450 MHz PULSE, 송신기의 최초 디지털 입력 PWL, 채널의 ideal buffer, 일부 바이어스 및 기능적 위상 검출기. 차별화된 증거와 원 논문의 저자 회로를 혼동하지 않는다.
- 상대적인 성공 판정: PLL은 오차 \(|\Delta f| < 1500\;\mathrm{ppm}\), 기준-클록 edge 위상 차이 표준편차 8 ps 미만, 필터 후 VCO 게이트 전압 변동 폭 5 mVpp 미만을 동시에 충족해야 한다. 이 지표는 결정론적 SPICE 파형 지표이며, 무작위 RMS jitter/phase noise 또는 2004년 ASIC의 BER 규격이 아니다.
- 수신 점수는 정수 비트 프레임 정렬을 사후 training 데이터로 결정하고, 분리된 holdout 구간의 UI별 샘플 누락/중복과 오판정을 별도로 기록했다. 동일 PRBS가 실제 제어 회로의 피드백 입력으로 사용되지 않았는지 각 실험 코드에서 점검했다.

## 2. 물리 PLL의 전 공정 코너 검증

### 2.1 Charge Pump 크기만 변경한 25개 물리 폐루프 테스트

실제 XSPICE PFD, DB HiTek MOS Charge Pump/VCO, RC 필터로 구성한 같은 기준 PLL을 TT/FF/SS/FS/SF에서 실행했다. 모든 코너의 초기 바이어스는 0.96 V로 유지했다. PMOS Source 및 NMOS Sink의 폭을 **함께** 50%, 65%, 75%, 85%, 100%로 스윕했다.

| Corner | 설정 판정 기준 통과한 공통 MOS 전류원 폭 비율 |
|---|---|
| TT | 50%, 65%, 75%, 85%, 100% |
| FF | 50%, 65%, 75% |
| SS | 75%, 85%, 100% |
| FS | 없음 |
| SF | 50%, 65% |

[실제 25건 GitHub Actions](https://github.com/khi103/EEE6682-Presentation/actions/runs/43174487711) 및 [실험 코드](../simulation/p3_global_pump_pvt.py).

**판정:** 시험한 5개 비율 중 모든 공정에서 수렴한 하나의 고정된 구성은 없다. 코너별 Gate Bias를 따로 최적화한 결과와 혼동하지 않는다.

### 2.2 FS 공정의 발진 주파수 공백

MOS Ring VCO의 바이어스에 대한 주파수 특성을 5개 코너에서 분리 측정한 결과, FS에서 NMOS 제어 전압이 0.65/0.75 V일 때 발진하지 않았고, 0.85 V부터 약 2.185 GHz로 발진했다. 즉, 시험한 unloaded VCO의 사용 가능한 바이어스 영역에는 목표 1.8 GHz가 포함되지 않았다.

VCO 각 단의 커패시턴스를 추가한 실제 MOS 전기적 스윕에서 FS, 0.85 V 제어 바이어스의 발진 주파수:

| 각 단 추가 부하 | 측정 주파수 |
|---|---:|
| 0 fF | 2.184718 GHz |
| 1 fF | 2.017548 GHz |
| 2 fF | 1.870653 GHz |
| 3 fF | 1.741166 GHz |

[원인 규명: VCO 코너 스윕](https://github.com/khi103/EEE6682-Presentation/actions/runs/43176596058), [부하 변경 30조건](https://github.com/khi103/EEE6682-Presentation/actions/runs/43177023021).

VCO 각 단에 추가한 3 fF와 MOS Charge Pump 원래 폭의 75% 조합을 실제 **폐루프**에서 검증한 결과, FS는 1.800013 GHz, 위상 차이 표준편차 0.112 ps, VCO 게이트 변동 폭 0.890 mV로 설정한 기준을 통과했다. TT, FF, SF도 통과했지만 SS는 1.697797 GHz, 약 167 ps의 위상 차이 표준편차를 보여 실패했다.

[실제 5코너 × 4 VCO 부하 폐루프 검증](https://github.com/khi103/EEE6682-Presentation/actions/runs/43177508051), [회로](../simulation/p3_global_vco_cap_pll.py).

**주의:** 3 fF는 원 저자 레이아웃에서 추출한 배선 기생 용량이 아니라 독립적인 회로 설계 변경 변수이다.

### 2.3 동일 VCO, 공통 Charge Pump 크기와 소자별 비대칭 조정

3 fF 추가 부하와 공통 초기 바이어스를 고정하고 MOS CP Source/Sink 폭을 80%, 90%, 100%, 110%, 125%로 함께 변경한 25개 시험에서 FF와 SS가 동시에 통과하는 공통 폭을 찾지 못했다. 82.5%, 85%, 87.5%로 더 좁힌 15개 시험에서도 FF와 SS의 동시 수렴을 확인하지 못했다.

- 82.5%: FF 통과(1.799445 GHz, 위상 차이 표준편차 5.72 ps), SS 실패(1.789574 GHz, 위상 차이 표준편차 213.8 ps).
- 85%: FF 실패(1.801500 GHz, 위상 차이 표준편차 16.27 ps), SS 실패(1.802371 GHz, 위상 차이 표준편차 51.8 ps).
- 87.5%: FF 실패(위상 차이 표준편차 11.77 ps), SS 실패(위상 차이 표준편차 11.88 ps).
- 90%: FF 실패(25.44 ps), SS 통과(6.15 ps).

[공통 폭 25조건](https://github.com/khi103/EEE6682-Presentation/actions/runs/43177986429), [세밀한 15조건](https://github.com/khi103/EEE6682-Presentation/actions/runs/43178849398).

PMOS CP Source 폭을 85/95/105%로, NMOS Sink 폭을 70/80/90%로 **독립적으로** 조정해 FF/SS 18개 회로를 실행했다. SS는 일부 조합에서 통과했으나 FF는 이 스윕의 모든 조합에서 설정 기준을 통과하지 못했다.

[비대칭 물리 Charge Pump 18조건](https://github.com/khi103/EEE6682-Presentation/actions/runs/43179165186).

또한 3 fF 추가 부하, Source/Sink 공통 75%, 초기 0.96 V 조건의 SS에서 실제 MOS **7-bit CP 제어 코드** 0/8/16/24/32/40/48/56/63/72/96/127을 스윕했다. **12개 코드 모두 실패**했다. 코드 0에서 주파수 1.7218 GHz, 코드 63에서 1.6978 GHz, 코드 127에서 1.6821 GHz였다. MOS 전류 DAC의 존재만으로 자동 PLL 코너 보정을 보장할 수 없다.

[물리 CP 7-bit 코드 12조건](https://github.com/khi103/EEE6682-Presentation/actions/runs/43179628355).

**남은 회로 설계 작업:** 하나의 초기 조건, 고정 RC, 고정 부하, 고정 CP 크기로 전체 5 Corner에서 동시에 Lock과 안정성을 확보할 것. 후보는 공통 startup-bias acquisition, CP current source/sink feedback linearity 조정, reference PFD reset timing, 실제 loop filter pole/zero redesign, MOS VCO 조정 범위 최적화다. 이것은 원 저자 회로의 실패를 의미하지 않는다.

## 3. 수신 데이터 기반 물리 MOS 위상 조절

두 단계 Current-Starved CMOS MOS 인버터로 구성한 수신 클록 지연 블록을 실제 reference-locked MOS VCO와 RX 사이에 연결했다.

| 외부에서 미리 설정한 MOS 지연 바이어스 | 물리 클록 지연 | +0.35 UI 기준 MOS RX 오류 |
|---|---:|---:|
| 지연단 미적용 | 73.15 ps | 27/227 |
| 1.25 V | 260.94 ps | 0/227 |
| 1.10 V | 282.26 ps | 0/227 |
| 0.95 V | 312.85 ps | 0/227 |

[물리 MOS 지연단 전기적 시험](https://github.com/khi103/EEE6682-Presentation/actions/runs/43174665092).

이후 동일 SPICE 회로에서 **수신된 RX 파형만** 입력으로 사용하는 행동 모델 B-source 위상 검출기의 출력을 실제 MOS 지연단의 커패시터 제어 노드에 연결했다. 초기 데이터 위상 오류 -0.05 UI/+0.95 UI와 초기 지연 바이어스 1.10 V 조건에서 각 156개 UI를 평가했다.

| 초기 위상 | 물리 피드백 OFF | 시험한 최선의 물리 피드백 조건 |
|---|---:|---:|
| -0.05 UI | 31/156 | 9/156 |
| +0.95 UI | 31/156 | 10/156 |

[물리 MOS 데이터 위상 피드백 challenge](https://github.com/khi103/EEE6682-Presentation/actions/runs/43176215586).

일부 피드백 극성과 강도는 개선하지 못하고 오류를 크게 늘렸다. 따라서 물리 지연단과 수신 데이터 간 실시간 피드백 연결, **조건부 수신 오류 개선**은 재현했지만, 원문의 정확한 네 XOR 기반 Bang-Bang Detector, Digital Saturating Counter, 실제 이중 루프 PLL의 완전 Lock까지 증명한 것은 아니다. PRBS 데이터는 피드백 제어에 사용하지 않았으며, 시험 후 오류 계산과 정수 비트 프레이밍에만 사용했다.

## 5. 실제 2단 CMOS TX Pre-driver, 공급 전력 및 수신 타이밍

초기 TX 전용 1.8-V PWL 제어 신호가 8개 출력 NMOS 게이트를 직접 구동하던 구성을, 두 단계의 실제 DB HiTek CMOS 인버터를 각 게이트에 연결하도록 변경했다. MOS TX, RC2 채널, MOS RX, 물리 MOS reference PLL은 같은 ngspice 넷리스트에서 작동했다.

| TX 구성 | FFE α=0 | FFE α=0.30 |
|---|---:|---:|
| Ideal TX gate PWL 직접 구동 | 12/156 | 2/156 |
| 실제 CMOS TX Pre-driver 2단 | 21/156 | 21/156 |

[물리 CMOS TX Pre-driver 통합 검증](https://github.com/khi103/EEE6682-Presentation/actions/runs/43178983217).

FFE α=0.30 조건에서 VDD 1.8 V 공급원의 시간 적분 **부분 전력**은 기존 2.5075 mW에서 Pre-driver 포함 5.3022 mW로 증가했다. 별도의 0.5 V TX 신호 공급 전력은 0.9400 mW에서 0.9884 mW가 됐다. 전력은 Pre-driver 단독 전력이 아니라 실제 MOS PLL, RX, Buffer 등을 포함한 공유 VDD의 합산이며, 원 저자의 27.12-mW 전체 Active Link Power와 비교할 수 없다.

물리 MOS clock-delay 블록을 추가하고 수신 타이밍을 다시 조절한 경우:

| 물리 MOS RX 지연 바이어스 | FFE α=0 | FFE α=0.30 |
|---|---:|---:|
| 지연단 없이 CMOS TX Pre-driver 연결 | 21/156 | 21/156 |
| 0.95 V | 6/156 | 2/156 |
| 1.10 V | 2/156 | 2/156 |
| 1.25 V | 2/156 | 2/156 |

[실제 CMOS Pre-driver + MOS Clock Retiming](https://github.com/khi103/EEE6682-Presentation/actions/runs/43179781968).

**결론:** 실제 Pre-driver의 전이 시간은 수신 판정 결과에 영향을 미친다. 물리 MOS 수신 타이밍을 보정하면 링크를 복구할 수 있지만 FFE 미적용 조건도 동일하게 개선되므로, 보정 후의 무오류 MOS Latch 결과를 FFE만의 이득으로 주장할 수 없다. Pre-driver는 원 논문 실제 Fig. 11–12 Slew-Rate Controller의 복제가 아니다.

| BER의 통계적 주장 | 충분한 독립 비트와 실제 수신 노이즈/지터, 재생 실패/전송 지연 포함한 샘플링 모델 |
| 27.12 mW 실리콘 전력 일치 | 모든 물리 TX predriver, PLL, RX 비교기/Offset/Demux, Termination Reference와 클록 배선/버퍼, 회로 레이아웃 기생 효과를 완전히 합산 |

공정 모델 라이선스 및 재배포 권한을 확인하기 전에는 파운드리 모델 원문을 공개 저장소, 첨부 ZIP 등에 재배포하지 않아야 한다.

## 7. 발표에서 사용할 수 있는 정직한 연구 결과 표현

**IEEE-style Academic English:**

> An independently reconstructed 3.6-Gb/s transmitter–receiver link was evaluated using transistor-level 0.18-μm CMOS models and a mixed-signal reference-locked PLL. Physical MOS offset trimming reduced the number of invalid or incorrect receiver decisions from 90 to 2 over a 358-symbol PRBS31 holdout interval under an intentionally introduced positive input-reference offset. A separate MOS clock-delay stage reduced receiver errors under unfavorable sampling-phase conditions; however, the result does not establish that the original four-XOR data-recovery controller was physically implemented. Introducing transistor-level transmitter predrivers substantially changed both partial supply power and the observed receiver error count, emphasizing the need to evaluate slew-rate and sampling-phase interactions rather than relying solely on ideal gate-drive simulations. The evaluated circuit remains an independent reconstruction rather than a transistor-level replica of the reported silicon.

**한국어 번역과 표현의 뉘앙스:**

> 독립적으로 재구성한 3.6 Gb/s 송수신 링크를 0.18 μm CMOS 트랜지스터 모델과 혼합신호 기준 클록 동기 PLL을 사용하여 평가하였다. 의도적으로 양의 수신 입력 기준 오프셋을 주입한 조건에서, 실제 MOS 소자 기반 오프셋 보정을 통해 PRBS31 독립 검증 구간 358개 심볼 중 유효하지 않거나 잘못 판정한 수신 결과를 90개에서 2개로 줄였다. 별도의 MOS 클록 지연 회로는 불리한 샘플링 위상에서 수신 오류를 감소시켰으나, 이 결과가 원 논문의 네 XOR 데이터 복구 제어기를 물리적으로 구현했음을 의미하지는 않는다. 실제 트랜지스터 수준 송신 Pre-driver를 추가하자 부분 공급 전력과 수신 오류가 모두 크게 달라졌다. 이는 이상적인 게이트 구동 결과만으로 성능을 판단하기보다 Slew Rate와 샘플링 위상의 상호작용을 검증해야 함을 보여준다. 검증 회로는 원 실리콘의 트랜지스터 수준 복제본이 아니라 독립적인 재구성 모델이다.

"Independently reconstructed"는 원 저자 소자 크기와 연결이 아닌 별도 설계임을 명시한다. "Reference-locked"는 450 MHz 외부 기준에 대한 PLL 수렴과 데이터를 이용한 CDR 수렴을 분리한다. "Invalid or incorrect decisions"는 누락 및 미재생 샘플도 오류에 포함하는 엄격한 기준이다. "Partial supply power"는 원 논문 전체 27.12 mW가 아닌 일부 회로 및 소스를 포함한 부분 전력이라는 뜻이다.
