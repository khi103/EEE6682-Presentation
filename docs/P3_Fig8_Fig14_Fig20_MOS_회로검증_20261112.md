# P3 Fig. 8, Fig. 14, Fig. 20: DB HiTek 180 nm 추가 회로 검증 (2026-11-12)

**목적:** 원 논문 회로에서 알려진 구조를 바탕으로 각 기능을 실제 MOSFET 모델과 ngspice로 독립 검증하고, 구현하지 못한 부분은 미완료로 표시.

## 3. Fig. 14 Comparator: 저속 트랜지스터 동작 일부 확인, 1.8 GHz 미달

PMOS 입력 차동쌍과 NMOS Current Mirror Load, CMOS 출력 버퍼를 실제 PDK MOS로 구성했다. 본 회로는 논문의 19개 소자를 그대로 배선한 회로는 아니다.

- TT, Vin−Vref=−30mV : Vout ≈ 0V; +30mV : Vout≈1.8V (정상 DC 판정)
- 독립 MOS 프리앰프의 DC 판정 문턱은 공정별로 크게 변함: TT 약 +24.83mV, FF +39.96mV, SS +15mV, FS +15mV, SF +86.14mV.
- 100MHz에서 **±150mV**로 큰 입력을 가한 경우 0V↔1.8V 출력이 관찰됨 (출력 약 1.809Vpp).
- **1.8GHz에서 ±35mV** 입력에서는 Transient 출력이 완전히 디지털 레벨로 재생되지 못함 (약 30µVpp만 변화).
- PMOS/NMOS 4-bit 전류 조절 MOS 코드를 5 Corner에서 탐색했지만 Code의 출력 변화가 과도하게 거칠어 **정밀한 Offset 보정 성공은 입증하지 못함**.
- 이것은 원 논문이 Positive Feedback Latch M11–M19와 Digitally Calibrated Offset을 쓴 이유를 설명하는 *실험 결과*다.

[실제 실행 및 결과](https://github.com/khi103/EEE6682-Presentation/actions/runs/43147732459) · [MOS Comparator](../simulation/p3_fig14_comparator_mos.py) · [Offset Current Trim](../simulation/p3_fig14_offset_current_trim.py)

**중요:** 100MHz 대진폭에서 동작했어도 논문 1.8GHz/35mV 목표를 충족하지 못했다. 최종 RX 시스템이 완성됐다고 발표할 수 없다.

## 4. Fig. 20 Charge Pump: 7-bit MOS DC 특성 검증 완료

PMOS Pull-up과 NMOS Base 및 1/2/4/8/16/32/64 Unit 7-bit NMOS Current DAC을 실제 PDK로 생성하고 출력 제어 노드를 0.9V에 클램프하여 156회 ngspice OP를 실행했다.

- TT, Code 0에서 Clamp Current = −46.43 µA; Code 127에서 −198.22 µA.
- TT에서 단위 코드 변화 약 −1.1952 µA/LSB, 전류 코드는 단조로움.
- 고정 0.9V DC 동작점의 최대 전류 코드 DNL 약 **0.000693 LSB**.
- 5 Corner 일부 코드 비교 수행.
- 이것은 전류 DAC의 DC 결과이며, Fig. 21에 제시된 실제 Clock Phase Shift 350ps 및 그 DNL과 **동일하지 않다**. VCO Kvco, 루프 이득 및 PFD/PLL 동작은 포함되지 않았다.

[실제 실행](https://github.com/khi103/EEE6682-Presentation/actions/runs/43147620804) · [MOS Charge Pump 코드](../simulation/p3_fig20_charge_pump_mos.py)

## 5. 블록별 통합 상태

- TX: 실제 ngspice 재구성 8:4:2:1 NMOS 드라이버, 2-Tap FFE, 출력 저항/전력/PVT/전압 코드, 확인 완료.
- TX Replica: MOS 실제 소자 + 이상화된 아날로그 제어기 및 Python 디지털 제어기, **독립 블록** 검증 완료, 원문 전체 TX에 폐루프 통합하지 않음.
- RX: PMOS 입력 Comparator 재구성 DC/100MHz 수준 확인, **1.8GHz 목표 미달**. 원문 M11–M19 Latch와 4-phase Sampling/Demux 미구현.
- Charge Pump: 7-bit MOS DC Current DAC 검증 완료, PLL 출력 Clock 실측/시뮬레이션 아님.
- CDR: 이전에 실제 MOS 수신 파형을 이용한 기능적 Bang-bang 위상 추적 검증 완료, 원문 Clock/Charge-Pump 회로와 연결되지 않음.
- 전체 링크: **TX→실제 채널→RX→PLL/CDR 전체 1.8GHz transistor-level 통합은 미완료**.
