## 1. 원본 PLL 실험 데이터 21개 확보 후 독립 계산

실제 수행됐던 GitHub Actions [run 43214358821](https://github.com/khi103/EEE6682-Presentation/actions/runs/43214358821)의 21개 원본 시뮬레이션 JSON ZIP을 모두 별도로 확보하여 분석했다.

### 1.1 기존 Window 간 중복

원래 분석 스크립트에서 늦은 주파수 구간의 세 창은

- [1000, 1080] ns
- [1080, 1160] ns
- [1120, 1200] ns

이었다. 마지막 두 창이 40 ns 겹친다. 이에 원본 JSON 안에 **이미 저장되어 있는** Window별 측정값으로 아래의 두 가지 후처리 평가를 수행했다. SPICE 재시뮬레이션이 아니라 **기존 수치 데이터의 독립 재분석**이다.

1. **연속, 비중복:** [920,1000], [1000,1080], [1080,1160] ns. 마지막 40 ns는 포함되지 않음.
2. **끝점까지 포함, 비중복:** [840,920], [1000,1080], [1120,1200] ns. 구간 사이에 공백이 있음.

두 방법 모두 주파수 Span 기준은 2 MHz 미만, 기존의 절대 주파수, 위상 표준편차, VCO 게이트 리플 및 종료 직전 Reference-Cycle Slip 기준은 그대로 적용했다.

| 판정 방식 | 통과 | 실패 |
|---|---:|---:|
| 기존 일부 중복된 80-ns 시간창 | 16 | 5 |
| 연속된 비중복 80-ns 시간창 | 16 | 5 |
| 마지막 시각을 포함한 비중복 시간창 | 16 | 5 |

**결론:** 21개 중 16개 통과라는 전기적 판정은 기존 측정 창을 서로 겹치지 않게 재선택하여도 바뀌지 않았다. 단, 개별 **주파수 변동 폭의 숫자는 실제로 바뀐다**. 그러므로 원래 중복 창에서 계산한 MHz 수치 자체는 최종 지표로 사용하지 않는다.

## 2. 원본 4-XOR 물리 MOS 검증의 디지털 상태 문제

GitHub Actions [원본 실험 43216227591](https://github.com/khi103/EEE6682-Presentation/actions/runs/43216227591)에서 4개 실제 시뮬레이션 결과 ZIP을 다시 확보했다.

- 피드백 전류 0 및 +100 μA
- 데이터 시작 위상 -0.05 UI 및 +0.95 UI
- 각각의 저장된 디지털-DAC 채널 출력 CSV 약 4,000행과 JSON 정량 결과 재분석

**네 조건 모두 다음이 측정됐다.**

- \`vup0\`, \`vdn0\`, \`vup1\`, \`vdn1\`: 모두 정확히 0.5 V로 고정.
- \`V(pdctrl)\`: 정확히 1.10 V로 고정.
- 실제 MOS RX 전압: 약 0.005–0.328 V 사이로 변화.
- Data Phase Feedback Gain에 무관하게 수신 오류 수가 똑같음 (시작 위상 -0.05 UI는 40/156, +0.95 UI는 36/156).

[ngspice XSPICE DAC 문서](https://nmg.gitlab.io/ngspice-manual/mixed-modeandbehavioralmodelingwithxspice/hybridmodels/digital-to-analognodebridge.html)에 따르면 \`out_undef=0.5\`는 **디지털 U (unknown)** 노드의 아날로그 매핑이다. 따라서 현재 실패의 직접적인 관측 증거는 **4-XOR의 아날로그 출력이 유효한 0/1이 아닌 U 상태로 고정되었다는 사실**이다. 단순히 수학적으로 UP/DOWN 신호가 서로 상쇄되었다고만 진단하는 것은 불충분하다.

가능한 원인은 RX ADC 값, MOS 클록 ADC 값, XSPICE DFF 비동기 Set/Reset 또는 DFF 샘플 데이터의 U 상태다. 아직 어느 단계에서 최초로 U가 발생하는지는 **확정되지 않았다**.

다음 진단에서 XSPICE RX/Clock ADC의 \`drx,dclke,dclko,dn1,dph2\`와 DFF 출력 \`dD0,dD1,dE0,dE1\`을 각각 별도 DAC로 읽도록 [원본 코드에 계측 채널을 추가](../simulation/p3_xspice_4xor_mos_cdr.py)했다. 수정된 실제 SPICE 런은 Runner가 배정되지 않아 아직 실행되지 않았다.

## 3. Transition-Qualified Alexander 대체 설계의 순수 논리 검증

기존 네 XOR 제어의 논리 가능 조합 16개 중 12개는 합산 제어가 0이 되는 조합임을 별도 확인했다. 이에 원 논문의 네 XOR 구조와 **정확히 동일하다고 주장하지 않는**, 전이 조건부 3-XOR + 2-AND의 Alexander Phase Detector를 설계했다.

\[
T=D_\mathrm{prev}\oplus D_\mathrm{next},\quad
UP=(D_\mathrm{prev}\oplus E)\land T,\quad
DN=(E\oplus D_\mathrm{next})\land T.
\]

- 8개 가능한 논리 조합에서 데이터 전이가 없으면 \(UP=DN=0\).
- 데이터 전이가 있으면 \(UP+DN=1\) (정확히 하나만 투표).
- PRBS31 512비트 시드 \`0x54C4EE17\`에서 전이 263개, 시드 \`0x13572468\`에서 전이 249개를 독립 계산했다.
- 이상적인 Early 전이 샘플은 모두 \((UP,DN)=(0,1)\), Late 샘플은 \((1,0)\)인 것을 순수 Python에서 확인했다.
- 실제 MOS 클록 기반 DFF, 전이 조건 XOR/AND, DAC 및 MOS 물리 지연단에 연결한 [실험 스크립트](../simulation/p3_transition_qualified_mos_bbpd.py)와 [PDK 불필요한 논리 검증 스크립트](../scripts/p3_verify_pd_logic_and_windows.py)를 작성했다.

**정확한 상태:** 위 숫자는 실제 트랜지스터 SPICE 시뮬레이션이 아니라 Python 논리식에 대한 Exhaustive Truth-Table 및 결정론적 PRBS 검증 결과다. 실제 MOS 클록의 DFF Sampling Aperture, ADC/DFF U 상태, 위상 루프 수렴 및 데이터 판정 오류는 아직 검증되지 않았다.

## 4. GitHub Actions 실행 인프라 장애

새로 작성한 DFF/ADC 계측 [10개 회로 시험](https://github.com/khi103/EEE6682-Presentation/actions/runs/43222383569)과 [실패 PVT 초기조건 24개 시험](https://github.com/khi103/EEE6682-Presentation/actions/runs/43223245568)은 모두 **Runner ID=0, steps=0, 실제 테스트 실행 이전 실패** 상태다. 간단한 [PDK 없는 논리 단위 시험](https://github.com/khi103/EEE6682-Presentation/actions/runs/43223024142)까지 같은 상태였다.

이 증상은 계정 Actions 사용량/결제 한도, Repository 정책 또는 Runner 프로비저닝 문제에서 생길 수 있지만, 계정의 Billing/Run Annotation 정보를 확인하지 않고 정확한 원인을 단정할 수는 없다. GitHub의 [공식 Actions Troubleshooting 문서](https://docs.github.com/en/actions/how-tos/troubleshoot-workflows)는 사용량 및 Budget 확인을 권고한다.

**현재 추가 완료 사항은 실제 21개 결과의 독립 감사, 4-XOR U 상태의 원본 파형 확인, Alexander 논리 진리표 검증, 디버깅용 코드와 CI 준비까지다.** 새 물리 MOS CDR 또는 24개 PVT 실험 성공을 보고하지 않는다.

## 6. 강의 FR4 Touchstone과 현재 RC2 모델의 차이

원 논문과는 다른 **강의용 100 Ω 차동 FR4 2-port** \`fr4_diff_100ohm*.s2p\` 네 개를 실제 GitHub 원본 텍스트로 읽어 S-parameter의 Option Line \`# Hz S RI R 100.0\`을 검증하고, 복소 S21을 주파수 축에서 선형 보간했다.

| 비교 대상 | S21(1.8 GHz), dB | S21(3.6 GHz), dB |
|---|---:|---:|
| 강의 \`fr4_diff_100ohm.s2p\` | -3.633 | -5.890 |
| 강의 \`fr4_diff_100ohm_mid.s2p\` | -3.370 | -5.677 |
| 강의 \`fr4_diff_100ohm_x36.s2p\` | -5.122 | -8.640 |
| 강의 \`fr4_diff_100ohm_x42.s2p\` | -6.014 | -10.152 |
| 현재 MOS 링크의 단순 Buffered 2-pole RC 근사 | -12.000 | 주파수 모델 자체는 있으나 강의 S21과 동일하지 않음 |

[강의 실제 Touchstone 원본](https://github.com/khi103/serdes-lecture-site/tree/main/linksim_H-L).

이 비교는 **동일 채널 재현**이 아니다. 강의 100 Ω Differential FR4와 Wong et al.의 50 Ω Single-Ended PCB/RG58 링크는 포트 임피던스, 전송 선로, 길이, Package/Connector가 다를 수 있다. 단지 기존 독립 MOS 링크의 RC2 -12dB@Nyquist 손실이 강의 채널 파일의 실제 Nyquist S21보다 크다는 사실을 확인한 것이다. 따라서 해당 RC2 결과를 논문 실측 Eye/BER와 직접 동일시할 수 없다.
